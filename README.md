# بوت تلجرام ذكي (مجاني) - نسخة محدثة

بوت بيجاوب على أسئلتك، بيرسل الأكواد كملفات، وبيحلل الصور والملفات (كود، PDF).
بيستخدم Groq كمحرك أساسي، وينتقل تلقائياً لـ Gemini كـ "احتياطي" إذا خلص الحد اليومي لـ Groq — بدون ما تنقطع المحادثة أو تتخربط الذاكرة.

## المفاتيح المطلوبة (كلها مجانية)

1. **TELEGRAM_BOT_TOKEN** — من @BotFather على تلجرام (`/newbot`)
2. **GROQ_API_KEY** — من console.groq.com > API Keys (المحرك الأساسي)
3. **GEMINI_API_KEY** — من aistudio.google.com/apikey (احتياطي + ضروري لتحليل الصور/PDF)

المتغير الثالث (GEMINI_API_KEY) اختياري تقنياً، لكن بدونه:
- ما رح يكون في fallback لما يخلص حد Groq
- ما رح يقدر البوت يحلل صور أو ملفات PDF (بس ملفات الكود/النص بتضل شغالة عبر Groq)

## كيف يشتغل نظام الـ fallback

- كل رسالة نصية بتروح أول شي لـ Groq
- إذا Groq رجع خطأ "تجاوزت الحد" (rate limit)، البوت بيعتبر Groq معطل لباقي اليوم تلقائياً، وبيحول كل الطلبات الجاية لـ Gemini
- **ذاكرة المحادثة موحدة** بين المزودين — يعني حتى لو تبدل المزود نص المحادثة، البوت بيفتكر كل شي قلتلو ياه قبل
- بعد منتصف الليل (بتوقيت السيرفر)، البوت بيرجع يجرب Groq من جديد أوتوماتيكياً

## تحليل الصور والملفات

- ابعت صورة (سكرين شوت كود مثلاً) مع أو بدون تعليق — البوت بيحللها وبيلاقي الأخطاء
- ابعت ملف كود (`.py`, `.js`, `.html`...) أو نص — البوت بيقراه ويحلله
- ابعت ملف PDF — بيتحلل عبر Gemini (لازم GEMINI_API_KEY معرّف)
- فيك تضيف تعليق (caption) على الصورة/الملف عشان توجه البوت شو بالضبط بدك تحليل (مثلاً: "لاقيلي شو غلط بهاد الكود")

## التثبيت والتشغيل

```bash
pip install -r requirements.txt

export TELEGRAM_BOT_TOKEN="التوكن_تبعك"
export GROQ_API_KEY="مفتاح_Groq_تبعك"
export GEMINI_API_KEY="مفتاح_Gemini_تبعك"   # اختياري بس موصى فيه بشدة

python bot.py
```

## على Railway

روح Variables وضيف ثلاث متغيرات بالضبط بهاد الأسماء:
- `TELEGRAM_BOT_TOKEN`
- `GROQ_API_KEY`
- `GEMINI_API_KEY`

وبعدين دوس Deploy.
