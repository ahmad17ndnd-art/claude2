# بوت تلجرام ذكي (مجاني)

بوت بيجاوب على أسئلتك وبيرسل الأكواد كملفات جاهزة للتنزيل، مبني على Python.

## شو بيحتاج (كلو مجاني)

1. **توكن بوت تلجرام** — من @BotFather على تلجرام:
   - افتح محادثة مع [@BotFather](https://t.me/BotFather)
   - اكتب `/newbot` واتبع التعليمات
   - رح يعطيك توكن شكله متل: `123456789:ABCdefGhIJKlmNoPQRstuVWXyz`

2. **مفتاح Groq API** — مجاني بالكامل:
   - سجل حساب على [console.groq.com](https://console.groq.com)
   - روح على API Keys واعمل مفتاح جديد
   - Groq بيدعم موديلات قوية متل Llama 3.3 70B بسرعة عالية ومجاناً (في حد استخدام يومي معقول)

## التثبيت والتشغيل

```bash
# 1. نصّب المكتبات المطلوبة
pip install -r requirements.txt

# 2. حط التوكن والمفتاح كمتغيرات بيئة
export TELEGRAM_BOT_TOKEN="التوكن_تبعك"
export GROQ_API_KEY="مفتاح_Groq_تبعك"

# 3. شغل البوت
python bot.py
```

على ويندوز (PowerShell):
```powershell
$env:TELEGRAM_BOT_TOKEN="التوكن_تبعك"
$env:GROQ_API_KEY="مفتاح_Groq_تبعك"
python bot.py
```

بديل أسهل: افتح `bot.py` وحط التوكن والمفتاح مباشرة مكان `ضع_توكن_البوت_هون` و `ضع_مفتاح_Groq_هون` (بس هيك أسلوب أقل أماناً إذا رح تشارك الكود مع حدا).

## كيف بيشتغل

- اكتب أي سؤال أو اطلب كود بالمحادثة مع البوت على تلجرام
- إذا الرد فيه كود (جوا ```)، البوت بيفصلو تلقائياً وبيرسللك ياه كملف (`.py`, `.js`, `.html`... حسب اللغة)
- الشرح النصي بيوصلك كرسالة عادية
- الأمر `/reset` بيمسح ذاكرة المحادثة وببلش من جديد
- الذاكرة موجودة بالرام بس (مش محفوظة بملف)، إذا عدت شغلت البوت رح تنمسح كل المحادثات

## ملاحظة

الموديل (Llama عبر Groq) إلو حد أدنى من قواعد أمان أساسية (مثلاً ما رح يعطيك كود فيروسات أو حاجات مؤذية)، بس لباقي الاستخدامات البرمجية والأسئلة العادية رح يشتغل معك بحرية كاملة ومجاناً.
